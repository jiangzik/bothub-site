# 开发者 API

BotHub 提供一套 **OpenAI 兼容**的 HTTP 接口。你在 BotHub 账户里的余额，可以直接用来从自己的
程序、脚本，或者交给一个 AI 助手去调用对话、生图、视频和向量模型。

因为接口是 OpenAI 兼容的，**任何支持「自定义 Base URL + API Key」的工具都能直接接上**——
OpenAI 官方 SDK、LangChain、各类客户端，以及 Claude、Codex 这样的编程助手。

## Base URL 与鉴权

```
https://bothub-api.bookab.info/v1
```

每个请求带上 API Key：

```
Authorization: Bearer bhk_live_xxxxxxxx
```

OpenAI SDK 只需要改两个参数：

::code-group

```python [Python]
from openai import OpenAI

client = OpenAI(
    base_url="https://bothub-api.bookab.info/v1",
    api_key="bhk_live_xxxxxxxx",
)

resp = client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

```javascript [Node.js]
import OpenAI from 'openai'

const client = new OpenAI({
  baseURL: 'https://bothub-api.bookab.info/v1',
  apiKey: 'bhk_live_xxxxxxxx',
})

const resp = await client.chat.completions.create({
  model: 'gpt-5.4',
  messages: [{ role: 'user', content: '你好' }],
})
console.log(resp.choices[0].message.content)
```

```bash [curl]
curl https://bothub-api.bookab.info/v1/chat/completions \
  -H "Authorization: Bearer bhk_live_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

::

## 先看看有哪些模型

**不要凭记忆猜模型名**。你的 Key 能用哪些模型、每个模型是什么类型，列一次就知道：

```bash
curl https://bothub-api.bookab.info/v1/models \
  -H "Authorization: Bearer bhk_live_xxxxxxxx"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "gpt-5.4",
      "object": "model",
      "owned_by": "bothub",
      "kind": "chat",
      "endpoints": ["/v1/chat/completions", "/v1/responses"]
    },
    {
      "id": "gpt-image-2.5",
      "object": "model",
      "owned_by": "bothub",
      "kind": "image_generation",
      "endpoints": ["/v1/images/generations"]
    }
  ]
}
```

`kind` 和 `endpoints` 是 BotHub 的扩展字段（OpenAI SDK 会忽略它们）：`kind` 告诉你这是对话、
生图、视频还是向量模型，`endpoints` 直接告诉你该往哪个地址发请求。

::note
列表只会包含**你这把 Key 有权限用**的模型。如果你要用的模型不在里面，先看 Key 的
[权限范围](/zh/api/errors)。
::

## 能做什么

| 能力 | 端点 | 说明 |
| --- | --- | --- |
| 对话 | `POST /v1/chat/completions` | OpenAI Chat Completions，支持流式、工具调用、视觉输入 |
| 对话（新版协议） | `POST /v1/responses` | OpenAI Responses API |
| 向量 | `POST /v1/embeddings` | 文本向量化 |
| 生图 | `POST /v1/images/generations` | [同步返回图片](/zh/api/images)，也可切异步 |
| 视频 | `POST /v1/videos` | [异步任务](/zh/api/images) |
| 图片编辑 / 视频续写 | `POST /v1/tasks` | 原生异步任务接口 |

**暂不支持**：语音合成（`/v1/audio/speech` 目前返回 `not_implemented`）、重排（rerank）没有对外端点。

## 把 Base URL 和 Key 交给 AI 用

如果你想让一个 AI 助手（Claude、Codex、某个 Agent 客户端）帮你调用，把下面这段话给它就够了：

```text
BotHub API 是 OpenAI 兼容的。
Base URL: https://bothub-api.bookab.info/v1
API Key: bhk_live_xxxxxxxx

先 GET /v1/models 看有哪些模型可用——每条结果里的 kind 和 endpoints
会告诉你它是什么类型、该请求哪个端点。画图用 POST /v1/images/generations，
它同步返回 data[0].b64_json。
完整文档：https://bothub.bookab.info/zh/api/overview
```

::tip
接口的错误响应是 OpenAI 格式的，而且 4xx 会带一个 `detail` 字段写明**下一步该做什么**
（缺哪个权限、该轮询哪个任务、哪个参数不对）。AI 读了它通常能自己纠正过来。
::

## 获取 API Key

在 BotHub App 里自己创建，三端都可以：

| 端 | 路径 |
| --- | --- |
| 桌面端 | 设置 → 模型服务 → BotHub 内置 AI → **外部调用** |
| Android | 设置 → 模型服务 → BotHub 内置 AI → **外部调用** |
| iOS | 设置 → BotHub 内置 AI → **外部访问** |

那个页面里能复制 Base URL、创建和吊销密钥，还能看到每把密钥最近 7 天的调用次数和花费。

::warning
API Key 形如 `bhk_live_xxxxxxxx_yyyyyyyy`，**只在创建时显示一次**，关掉弹窗就再也看不到了，
请当场复制保存。它等同于你账户余额的支付凭证——不要提交进代码仓库，不要写在前端页面里；
一旦泄露，回到同一个页面吊销它。
::

新建的密钥默认带上全部权限（对话、生图、视频、向量），可以直接用。
